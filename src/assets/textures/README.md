# Шаблоны текстур

Добавляйте сюда PNG, JPG/JPEG или WebP. Приложение автоматически покажет
их квадратными карточками в разделе паттерна. Имя файла без расширения
используется как подпись; дефисы и подчёркивания заменяются пробелами.

Индекс 0 — пользовательская загрузка, 1 — без текстуры. Шаблоны начинаются
с индекса 2 и сортируются по имени файла с учётом чисел. Для стабильного
порядка используйте префиксы `01-`, `02-` и т. д. Индексы обозначают порядок
карточек, а не UV-каналы. После добавления файлов обновите страницу;
для опубликованной версии потребуется новая сборка.

Рекомендуются квадратные бесшовные текстуры. SVG не поддерживается.
Публикуйте только изображения, права на распространение которых у вас есть.

Карточки используют автоматически созданные WebP-превью до 192×192 px.
Оригинал загружается на модель только после выбора. Генерация выполняется
при запуске Vite и сборке; добавленные или изменённые файлы подхватываются
и во время работы dev-сервера. Вручную: `npm run textures:previews`.
Превью находятся в соседней папке `src/assets/texture-previews`, исключены
из Git и восстанавливаются из исходников. Оригиналы не изменяются;
одноимённые файлы разных форматов сохраняются как отдельные карточки.
